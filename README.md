## Kansiorakenne

```text
metropolia-webdev/
├── README.md
├── html-css/
└── js1/
    ├── index.html
    ├── styles.css
    ├── module-1-2/
    │   ├── index.html
    │   └── exercise-1/ ... exercise-8/
    └── module-3/
        ├── index.html
        └── exercise-1/ ... exercise-5/
```

Tehtävät voivat olla vielä keskeneräisiä, ja päivitän tätä repositoriota kurssin edetessä.

> GitHub Pages -linkit toimivat, kun repositorion Pages-asetuksissa julkaisu on päällä ja lähteeksi on valittu `main`-haara sekä `/(root)`.
